# Skimming and Scanning

Interactive reading lesson with skimming, scanning, quiz, and review activities.

## Open the lesson

- Open `Riya demo - final.html` for the self-contained bundled lesson.
- Open `Riya demo.html` for the lesson that loads its activity pages from this folder.

Keep the linked activity HTML files in the same folder as `Riya demo.html`.
The quiz page uses online fonts and styling resources.
