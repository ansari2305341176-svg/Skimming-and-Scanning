# Skimming and Scanning

Interactive reading lesson with skimming, scanning, quiz, and review activities.

## Open the lesson

- Open `index.html` or `Riya demo - final.html` for the self-contained bundled lesson.
- Open `Riya demo.html` for the lesson that loads its activity pages from this folder.

Keep the linked activity HTML files in the same folder as `Riya demo.html`.
The quiz page uses online fonts and styling resources.

## Deploy on Vercel

The project is static HTML and needs no build step or server runtime. Import this
GitHub repository into Vercel and deploy from the repository root. If prompted
for settings, choose the `Other` framework preset, leave the build command empty,
and set the output directory to `.`. Vercel serves `index.html` as the home page.
